PROJECT OVERVIEW

開發目標

打造可從影像來源一路延伸至風險研判與行動端呈現的模組化系統。

  • 攝影機影像接入與串流管理
  • 影像解碼、轉檔與播放驗證
  • AI 視覺辨識模型整合規劃
  • Functional Risk Prediction AI Agent
  • 行動 APP 監看及風險資訊介面

CAPABILITIES ROADMAP

核心功能與開發方向

01 / STREAMING
多來源影像串流

連接 CloudEdge/Meari 與 IP Camera，整合串流接收、轉發與影片播放流程。

02 / COMPUTER VISION
AI 視覺辨識

規劃導入影像事件偵測與辨識模型，將影音資料轉換為可供分析的事件資訊。

03 / PREDICTIVE AGENT
功能性風險預測 AI Agent

規劃整合視覺事件、歷史趨勢與規則或模型推論，支援風險提示及後續決策輔助。
